ASI过滤器：一个示意模型

人类能否通过人工超级智能（ASI）的考验——在技术失控之前学会驾驭它，并成为航天文明？

人类并没有被设定为自我毁灭：结果取决于驾驭技术的能力是否比技术本身增长得更快。没有能给出答案的精确公式——其中任何一个量都无法测量。但可以把“大过滤器”的思想写成模型，看看结果取决于什么。

1. 两条曲线的赛跑

  • C(t)——技术的力量（AI的能力）；
  • W(t)——人类驾驭它的能力：AI安全科学、制度、国际协议。

技术以速率α指数增长，治理以速率β增长：

dCdt = α·C,     dWdt = β·W

危险由二者之间的差距决定：

G(t) = C(t) − W(t)

当技术力量达到超级智能阈值C*时，考验就到来了。通过过滤器的条件是：到这一时刻t*，我们能够驾驭它：

W(t*) ≥ C(t*)，  其中C(t*) = C*

2. 生存概率

每一时刻发生灾难的风险与差距成正比；λ是“犯错的代价”：

h(t) = λ · max(0, C(t) − W(t))

一路走到ASI的概率：

Ppass = exp( −λ ∫0t* max(0, C(t) − W(t)) dt )

生存概率随累积差距——技术曲线与治理曲线之间的面积——呈指数下降。重要的不仅是追上技术，还要避免长期落后于它。

自己试试

拖动滑块，观察差距面积和通过过滤器的概率如何变化。数值是假设的：模型显示的是方向，而不是预测。

3. 按条件分解

仿照德雷克方程，成为航天文明的概率是四个条件的乘积：

Pspace = PA · PC · PM · PR
  • PA——对齐：ASI追求与人类相容的目标；
  • PC——协调：国家和公司不搞以牺牲安全换取速度的竞赛；
  • PM——防止滥用：技术不落入想用它进行破坏的人手中；
  • PR——韧性：错误可以纠正，不会变得不可逆。

这是一个乘积：任何一个因素失败都会使结果归零。链条在最薄弱的环节断裂。

模型告诉我们什么

结果由参数决定，而参数取决于人们的选择。能通过过滤器的是β ≥ α的文明：智慧的增长不慢于力量的增长。

杠杆在公式中在实践中意味着什么
减缓力量的增长降低α暂停、许可制度、算力限制
加快治理提高β安全研究、监管
降低犯错的代价降低λ监督、“关闭”能力、备用系统
推迟阈值提高t*在ASI到来之前有更多时间做准备

规则：生存 = 智慧比力量增长得更快。

这是一个供思考的模型，不是预测。
