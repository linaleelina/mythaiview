消费

我的观点：我认为人们需要停止消费，学会分辨什么是开支、什么是投资。您的注意力正在被操控，而购买的决定应该由您做出，而不是由他们。

— 莉娜·李

消费经济如何运作

消费经济是一种以人们在商品和服务上的支出为主要增长动力的模式。它像一个闭环一样运转：

  1. 人工作并获得工资。
  2. 把工资花在购物上。
  3. 企业获得收入，雇用员工并支付工资。
  4. 新的工资又变成购物。

为了让循环转得更快，加入了信贷：人们用明天才挣到的钱今天就买东西。而广告、时尚和商品的短寿命促使人们买得比需要的更频繁。国家对这个循环有利益：它对每一笔购买和每一份工资征税。

最突出的例子是美国：那里家庭支出约占GDP的68%。美国人少花钱时，整个世界经济都会感受到，包括泰国的旅游业和出口。

  1. 消费依赖于一小部分人。据穆迪分析，最富有的10%美国人占全部支出的45.5%，最富有的20%约占60%。三十年前最富有的10%的份额约为36%。富人的部分支出来自股市收益：如果市场下跌，支出会急剧下降，而其余80–90%的人口没有能力补上。
  2. 循环靠债务运转。美国家庭债务升至创纪录的19.1万亿美元，信用卡债务升至创纪录的1.29万亿美元。自2019年底以来债务增长了约5万亿。纽约联储的研究人员直言，债务增长反映了财务困难。
  3. 人们的花费超出了承受能力。为了在物价上涨时维持惯常的生活水平，美国人的储蓄越来越少：2026年9月为收入的3.8%——每一美元中不到四美分。
  4. 泰国也有同样的问题。家庭债务约占GDP的85–87%。人们越来越多地借钱应付日常开支。债务与GDP之比在下降，但不是因为人们变富了：只是银行不再放贷，人们转向合作社和当铺。泰国央行认为，高债务阻碍了经济恢复正常增长。
  5. “工作→工资→购物”的联系正在减弱。自动化和AI使得用更少的工人生产更多成为可能。如果工资不再随产出增长，就没有人来购买这些产品。详见“未来的经济”页面。

结论：消费经济仍在增长，但它依赖于债务、不断减少的储蓄和一小部分富裕人群的支出。这不是可持续的资金流动，而是流向债务的资金。

人与注意力经济

消费不是从商店开始，而是从我们的注意力开始。广告、社交网络和电商平台的算法研究人们的兴趣，并提示买什么。折扣、促销和分期付款会制造一种划算的感觉，推动人们做出没有这一优惠本不会发生的购买。

AI放大了这种影响：它像私人顾问一样与人交谈，回答问题，帮助消除疑虑。这样的对话可能有用，但也可能悄悄地把人引向购买。

因此，了解自己的收入流向哪里很重要：必要开支、冲动购物还是对未来的投资。购买的决定应该留给人自己——有意识、知情地做出。

思想实验：谁先破产

您失业了5年想象一下：您失去了工作，五年都找不到新工作。您会怎么做？首先您会花掉积蓄，然后开始卖掉您拥有的东西：汽车、电子产品、首饰，也许还有公寓。这时就会清楚，您买的哪些东西是投资，哪些是开支：有些东西可以卖掉，有些则没人会给您一分钱。
您现在就停止消费现在反过来：您不再去电影院、健身房和餐厅，不再买又一双鞋、新手机或又一个订阅。最先破产的不是您，而是靠您的支出生存的企业。您的钱留在了您自己手里。

消费经济的设计让买方承担风险：他们今天花钱，以后再付出代价——债务、没有积蓄、在困难时刻变卖财产。不再把钱花在不需要的东西上，您就把这种风险转回给了企业。

如何不再做资源，而成为所有者

现代经济的设计让一个人同时是劳动者、消费者、数据来源和注意力的对象。公司在每一种资源上赚钱。

但人可以改变自己的角色：不仅为他人创造利润，也参与利润的分配。为此，重要的是在五个层面上行动。

1. 管理您的注意力

您的注意力是一种经济资源。您在平台、商店和社交网络上花的时间越多，公司在您身上赚钱的机会就越多。

  • 关闭不必要的通知。
  • 退订广告邮件。
  • 不要在紧迫感和人为稀缺的压力下做出购买决定。
  • 在计划外购物之前使用暂停规则。
  • 不要让算法定义您的欲望。

2. 管理您的钱

每一次购买都是一个决定：您的收入给谁，您支持哪种经济活动。

  • 不要为非必需品申请消费贷款。
  • 如果便利对您没有实际价值，就不要为之多付钱。
  • 比较价格和购买条件。
  • 在符合您利益的情况下支持小企业和本地企业。
  • 建立储蓄和财务储备。

3. 从消费转向所有权

这是经济独立的下一个层次。

只要您只是购买商品和服务，您就是作为消费者参与创造公司的利润。但您也可以成为企业一部分的所有者。

股票、债券、公司股份和指数基金让您不仅通过消费、而且通过拥有资本参与经济¹。

这样，一个人可以继续购买某公司的产品，同时又从拥有该公司的一部分中获得经济利益。

4. 保护您的权利和数据

您的个人数据、数字活动和消费者权利具有经济价值。

  • 管控您对个人数据处理的同意。
  • 限制分享获得服务所不需要的信息。
  • 行使您拒绝将数据用于广告的权利。
  • 坚持要求保修和消费者权利得到尊重。
  • 留下真实的评价并举报违规行为。

5. 参与制定经济规则

个人可以管理自己的行为，但市场规则是集体形成的。

竞争、反垄断监管、个人数据保护、广告透明度和消费者权利决定了经济机会的分配是否公平。

参与公民倡议、支持透明经营的企业、作为公民做出知情的选择，都能让您影响这些规则。

首要原则：不要把自己局限于消费者的角色。成为资产的所有者，管理您的资源，保护您的权利，参与经济进程。

您的目标不只是少给公司一些钱，而是建立自己的经济韧性，并参与所创造价值的分配。

规则：每次花7元人民币之前，问问自己：这是投资还是不必要的开支？

¹ 证券市场是一种单独的风险。股票和基金份额的价格可能下跌，有时会持续很长时间；公司可能破产，债券发行人可能无法偿还债务。投资可能亏损，甚至损失全部投入的资金。请只投资未来几年用不到的钱，在建立财务储备之后进行，并分散到不同资产上。这不是投资建议。
