房产付款

外国人如何在泰国支付公寓款项：资金必须来自哪里、用什么货币、哪份文件证明汇款，以及六种付款方式中哪种最便宜。

境外汇款和FET表

要以永久产权登记公寓，外国人必须证明资金以外币从境外汇入。为此银行会出具外汇交易表（FET）。盘谷银行通过SWIFT接收此类汇款，可汇入泰铢账户或外币账户。

通过Wise等服务汇的款项由当地合作伙伴在泰国境内支付，因此形式上不算国际汇款，服务商本身也不能出具FET表。需要向款项经由的合作银行申请。

为什么泰国账户没有IBAN

IBAN（国际银行账号）主要在欧洲和中东使用。泰国不属于IBAN体系，因此泰国账户没有IBAN。盘谷银行明确表示它没有IBAN，汇款人无需提供；需要的是银行的SWIFT代码。

向泰国汇款时，汇款人需要：

  • 账户持有人姓名——与银行记录完全一致；
  • 账号——只填数字，不加空格或连字符（各银行位数不同）；
  • 银行名称和SWIFT代码，例如盘谷银行BKKBTHBK、开泰银行KASITHBK、汇商银行SICOTHBK、大城银行AYUDTHBK；
  • 付款用途——例如购买公寓，写明房号和项目名称。

如果您的银行没有IBAN就不受理汇款，请在该栏填写泰国账号，或在银行允许时留空，并务必填写SWIFT代码。如果仍不行，请询问您的银行如何向没有IBAN的国家汇款。

付款链条：从您的账户到开发商

在境外有账户的外国人向泰国开发商支付公寓款项的六种方式，从最便宜到最贵。每种方式都标明是否适用于以永久产权登记公寓。

排名基于典型的费用结构：货币兑换几次、涉及几家银行、汇率由谁决定。确切金额取决于您的银行、金额和币种。唯一有官方数据的是泰国银行接收SWIFT汇款的手续费：0.25%，最高500泰铢。●——相对成本；蓝色方块是在泰国境内的步骤。

1
汇款服务（Wise等）以泰铢汇款
您的境外账户 → 汇款服务 → 泰国合作银行 → 您在泰国的账户 → 开发商账户
服务费 + 按接近市场汇率兑换。泰国银行对入账不收费：款项以境内转账形式到账。
●○○○○○永久产权：不确定
通常是最便宜的方式，但款项以泰铢、境内转账形式到账。以永久产权登记公寓需要合作银行出具资金来自境外的证明，而这种证明并不总能开出。
2
SWIFT外币直接汇入开发商账户
您的境外账户 → 代理行（如需要） → 开发商的银行
您的银行汇款手续费 + 中间行费用（如有）+ 泰国银行入账费0.25%、最高500泰铢 + 按泰国银行汇率兑换成泰铢一次。
●●○○○○永久产权：可以，有FET表
适用于永久产权的方式中最短的路径：一次兑换，一个收款人。在付款用途中写明您的姓名和用途——购买公寓并写明房号——这样FET表会以您的名字出具。
3
SWIFT外币汇入您在泰国的账户，再付给开发商
您的境外账户 → 代理行（如需要） → 您在泰国的账户 → 开发商账户
与方式2相同，另加一次泰国境内转账：通过PromptPay或ITMX在限额内通常免费；大额款项通过银行本票或BAHTNET另行收费。
●●●○○○永久产权：可以，有FET表
比方式2稍贵稍慢，但在每次付给开发商之前资金都在您的掌控之中——分期付款时很方便。FET表由您的银行出具。
4
SWIFT，但由汇款方银行兑换货币
您的境外账户 → 在境外兑换成泰铢 → 代理行 → 开发商的银行
费用与方式2相同，但兑换泰铢的汇率由外国银行决定——通常比泰国银行的汇率差。
●●●●○○永久产权：不可以——款项不是以外币到账
常见错误：汇款一开始就以泰铢汇出。外国人购买永久产权必须以外币汇入资金，因此汇款时请选择美元、欧元或其他外币，而不是泰铢。
5
银行卡支付
您的银行卡 → 卡组织 → 开发商的收单行 → 开发商账户
您的银行的境外交易手续费和卡组织的货币兑换；开发商可能另加收卡手续费。
●●●●●○永久产权：不可以
只适合支付少量订金。大额款项不用银行卡支付：费用高，有限额，而且不会有FET表。
6
外币现金、加密货币或P2P兑换
现金、加密货币或P2P → 在泰国兑换 → 开发商账户
按兑换点或交易所的汇率；携带超过20,000美元现金入境须向海关申报。禁止用加密货币向开发商付款。
●●●●●●永久产权：不可以
最贵、风险最大的路径：这不是境外汇款，没有FET表，大额现金和加密货币会引起银行和监管机构的注意。P2P兑换时，泰铢来自陌生人的账户——如果是骗子的钱，您的账户可能被冻结（详见P2P兑换）。

如果由亲属汇款

亲属、配偶或您的公司也可以为公寓付款。法律并不禁止，但汇款必须与买方明确关联。

+
从亲属账户以SWIFT汇出外币
亲属的境外账户 → 代理行（如需要） → 您在泰国的账户或开发商的银行
费用同方式2和3。付款用途：“Purchase of condominium unit No. … in … by [与护照一致的您的姓名]”。
永久产权：可以，前提是汇款中写明买方
最好由买方本人作为收款人——汇入其泰国账户。各地土地办公室做法不同：有的接受付款用途正确的第三方汇款，有的要求买方姓名作为汇款人或收款人出现在FET表上。请提前向银行以及律师或开发商核实。
  • 金额没有限制。每笔汇款50,000美元的门槛只决定文件类型：达到该金额银行出具FET表；低于该金额出具入账通知（credit advice）和银行确认函。土地厅两种都接受。
  • 不要为绕开门槛而拆分汇款：要核对的文件会更多，问题也会更多。
  • 保留与汇款人关系的证明文件：赠与书、结婚证或公司决议。

如何选择

如果公寓以永久产权登记，请选择方式2或3：能可靠取得FET表的最便宜方式。方式1更便宜，但对永久产权风险更大。方式4–6不适合外国人购买公寓。

规则

规则：购买公寓的钱请以外币通过SWIFT从境外直接汇入泰国银行，并在泰国银行兑换成泰铢。付款用途写明您的姓名和用途——购买公寓。款项入账后立即索取FET表：没有它，外国人无法登记永久产权。

规则：为了让境外汇款显示为国际汇款，请在直接通过SWIFT收款的银行开户，并提供其代码。这样FET表就由您自己的银行出具。

为什么汇款可能经由中间行到账并看起来像境内转账，详见“盘谷银行”页面。购房的税费见“购房与费用”页面。银行和土地办公室向AMLO报告哪些付款，见“AMLO”页面。
